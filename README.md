# Text Classifier --- R Programming

## Overview

This project explores text classification using the R programming
language.

## Contents

-   `code.R` --- R source code for the analysis and classification
    workflow.
-   `projekt_analiza_danych.pdf` --- project documentation and analysis.
-   `Suicide_Detection_shorter.csv` --- dataset used in the project.

## Tools

-   R
-   Data analysis
-   Text classification
-   CSV data

## Project Focus

The project demonstrates a text-classification workflow using R and a
labeled text dataset.

## Data

The repository contains a shortened dataset related to suicide
detection. The dataset is included for educational and analytical
purposes.

## How to Explore

Run `code.R` in an R environment to review the analysis and
classification workflow.

## Purpose

This project demonstrates practical experience with R, data analysis,
and text classification.
